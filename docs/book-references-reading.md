# Reading shelf additions

Each model uses the publisher’s rounded dimensions for the listed US print ISBN, including the binding thickness. Each front texture is downsampled from the publisher’s downloadable TIFF with its embedded color profile converted to sRGB when supplied. The spines and rear panels are interpretations. They use each edition’s palette, typography and selected cover details. The jackets’ rear descriptions are original summaries and the barcodes encode the listed ISBN. Cover illustrations, photography, type designs and publisher marks belong to their respective owners.
